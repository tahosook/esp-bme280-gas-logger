# リリース計画

GAS Web Appの本番リリースと旧システム廃止までの手順を整理する。

---

## 前提

- 旧システムは停止済みで、並行稼働は行わない。
- 本番デプロイと旧廃止は人間の承認後に実施する。

---

## 本番デプロイ手順

1. スプレッドシートを作成し、DATAシートの先頭行を用意する。
2. タイムゾーンを`Asia/Tokyo`に設定する。
3. GASプロジェクトを作成し、`gas/Code.gs`を反映する。
4. Script Propertiesに必要なキーを設定する。
5. Web Appを`/exec` URLでデプロイする。
6. Webhook/LINE/トリガーを設定する。
7. スモークテストを実施する。

---

## ロールバック方針

| 観点 | 方針 |
| --- | --- |
| 切り替え | 旧システムは停止済みのため、並行稼働によるロールバックは行わない |
| 復旧 | 問題発生時は新システム内で修正・再デプロイする |

---

## ロールバック手順

1. 新システムのWeb Appデプロイを停止または以前のバージョンへ戻す。
2. 原因調査と修正を実施する。
3. 再度本番デプロイへ進む。

---

## 旧システム廃止条件

- 新システムが最低1週間安定して動作している
- データ欠損/重複が許容範囲内である
- 通知/監視が旧システム同等以上に確認されている
- 人間による旧廃止承認が得られている

---

## 人間による承認が必要なタイミング

- スプレッドシート構成の最終決定
- Script Propertiesのキー/値の決定
- 本番Web Appデプロイ
- LINE/Webhook設定の変更
- 本番切り替え
- 旧システム廃止
