# テスト計画

GAS API、日次処理、監視、LINE Bot、本番確認のテスト項目を整理する。

---

## テスト方針

- GAS単体、実機統合、本番確認の順に検証する。
- 秘密情報はテスト記録に含めない。
- 検証結果は`docs/test-results/`に日付付きで記録する。

---

## GAS API単体

| ケース | 期待結果 |
| --- | --- |
| 正常なJSON | HTTP 200、 DATAに1行追加 |
| JSON解析不能 | invalid_json 、追加なし |
| 必須項目欠損 | invalid_payload 、追加なし |
| api_version 不一致 | invalid_api_version 、追加なし |
| トークン不一致 | invalid_token 、追加なし |
| 範囲外の数値 | invalid_payload 、追加なし |
| 境界値 | 受理され、DATAに1行追加 |
| 未知フィールド | 無視されて受理される |
| 内部エラー | internal_error |

---

## 日次処理

| ケース | 期待結果 |
| --- | --- |
| 前日データの集計 | Average/Min/Maxが正しい |
| 複数日連続実行 | 日別シートが破綻なく増える |
| データ件数変動 | 件数が少ない日でもエラーにならない |
| TOTAL整合性 | TOTALの値と日別シートが一致する |

---

## 環境監視

| ケース | 期待結果 |
| --- | --- |
| 閾値超過 | LINE通知が送られる |
| 超過継続 | 連続送信されない |
| 正常復帰 | 状態がリセットされる |
| 再超過 | 復帰後に再通知される |
| スキップ中 | 通知が抑制される |
| クリア後 | 監視が再開される |

---

## LINE Bot

| ケース | 期待結果 |
| --- | --- |
| 「状況」 | 現在値/閾値/状態が返る |
| 「スキップ」 | 翌朝8:00まで監視停止 |
| 「クリア」 | 監視停止が解除される |
| 不明コマンド | エラーでなく補足案内が返る |
| 非テキスト | 非対応として応答する |

---

## 本番確認

| 項目 | 確認内容 |
| --- | --- |
| データ送信 | 実機から送信しDATAに保存される |
| 重複送信 | 重複時も破綻しない |
| 欠損 | 許容範囲内であること |
| 日次処理 | 日別シート/TOTALが更新される |
| 通知 | 条件超過で通知され、抑制/再通知が機能する |
| エラー | GAS/LINEエラー時に原因追跡が可能 |
| 容量 | Spreadsheet容量/実行時間が運用範囲内 |

---

## 長期運用確認

- リリース後1時間: データ欠損/トリガー実行/通知の初動確認
- リリース後1日: 日次処理/通知抑制の経日確認
- リリース後1週間: 容量/実行時間/エラー率の安定性確認
