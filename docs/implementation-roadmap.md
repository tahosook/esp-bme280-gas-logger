# GAS環境ロガーシステム 実装ロードマップ

本ドキュメントは、旧システムから新システムへの移行について、
GAS/スプレッドシート/LINE 側を対象に、実装開始から本番リリース・安定運用開始までを
明確な工程に整理する。

参照した旧システムコード：
- `/Users/tahosook/Downloads/仕事部屋環境ビジュアライザー_Code.gs`
- `/Users/tahosook/Downloads/気温湿度監視_Code.gs`

旧システムで確認された機能は以下の通り。
- 日別シートの自動作成
- Average / Min / Max / グラフ
- TOTALシート
- 温度/湿度/WBGTの閾値監視
- 直近4件平均による監視
- スキップ / クリア / 状況 のLINE操作

---

## 全体方針

- 生データは一方向に保存する。集計処理で生データを破壊・上書きしない。
- 旧実装の固定行数や固定範囲、ambidata API依存は仕様として継承しない。
- 重複POSTは排除せず、受信したデータをそのままDATAに記録する。
- 実装タスクは最小単位に分割し、CLINE Freeモデルで1回ずつ進められるようにする。
- 人間による承認が必要な判断は、実装前に確定する。

## 継続判断のルール

- 仕様未確定のまま実装しない。要判断項目はPhase 1で確定する。
- 各Phase完了後、次に進む条件を満たさない場合は次Phaseへ進まない。
- 旧システムの実装は仕様の参考に留め、必要な機能だけを新システムへ翻訳する。
