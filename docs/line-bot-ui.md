# LINE Bot UI / UX 仕様

## 1. 概要
ESP8266 + BME280 のセンサーログを活用した LINE Bot の応答やアラート通知を、テキスト主体から視覚的な「Flex Message」に移行し、同時に24時間の温湿度推移をグラフ画像で確認できる機能を提供します。

## 2. Flex Message のレイアウト仕様

### 2.1 状況 / status コマンドの応答
最新の測定値を含むリッチカードを返信します。

- **ヘッダー/タイトル**: 現在の監視状況
- **表示項目**:
  - 気温 (℃) [正常/超過]
  - 湿度 (%) [正常/超過]
  - 不快指数 (DI) [正常/超過] ＋ 色付きのステータスバッジ (例: 肌寒い、快適、やや暑い、暑くてたまらない)
  - 容積絶対湿度 ($g/m^3$)
  - 最終受信日時
- **フッター (Quick buttons)**:
  - `[ 🔕 翌朝までスキップ ]`
  - `[ 🔔 クリア ]`

### 2.2 スキップ / skip コマンドの応答
「翌朝 8:00 JST までアラート停止」を反映した完了カードを返信します。
- フッターに `[ 🔔 監視を再開（クリア） ]` ボタンを配置し、誤操作時の即時復旧をサポートします。

### 2.3 アラートプッシュ通知
監視閾値を超過した際のプッシュ通知も Flex Message 化します。
- 異常時の数値と判定を含みます。
- メッセージ下部に `[ 🔕 翌朝8時までスキップ ]` ボタンを直接配置し、1タップでスキップを実行可能とします。

## 3. リッチメニューの推奨配置
操作性を高めるため、LINE Official Account Manager 等で以下の 3 枠リッチメニューの配置を推奨します。

- **左枠**: `[🔕 スキップ]` (アクション: テキスト「スキップ」を送信)
- **中央枠**: `[🌡️ 状況]` (アクション: テキスト「状況」を送信)
- **右枠**: `[📈 グラフ]` (アクション: テキスト「グラフ」または「24h」を送信)

## 4. 直近24hグラフ画像生成機能
コマンド「グラフ」または「24h」を受信すると、直近の24時間分（5分間隔で最大288件）のデータをもとに折れ線グラフを生成し、LINEへ画像として返信します。

- **グラフ生成エンジン**: [QuickChart API](https://quickchart.io/) を使用します。
- **データ取得元**: 現在アクティブな Google スプレッドシート (`DATA` または `2026` 等のシート) から直近最大 288 行を取得。
- **グラフの仕様**:
  - X軸: 時刻 (HH:mm)
  - Y軸 (左): 温度 (℃) / 赤色 (`#e74c3c`)
  - Y軸 (右): 湿度 (%) / 青色 (`#3498db`)
- **配信方法**: LINE Messaging API の `image` メッセージタイプ (`originalContentUrl` / `previewImageUrl`) としてユーザーに配信されます。
